# imx91-rgb-controller

This is a Matter-based RGB LED controller running on the **NXP FRDM i.MX 91S** development board.

## Tech Stack
* **Language**: Node.js (JavaScript / TypeScript)
* **Matter Library**: `@project-chip/matter-node.js`
* **Hardware Interfacing**: Linux PWM/GPIO via Node.js file system API

## Getting Started

1. Install dependencies on the EVB:
   ```bash
   npm install
   ```
2. Start the Matter lighting app:
   ```bash
   npm start
   ```
3. Scan the generated QR code in your **Google Home App** to add it to your smart home!
